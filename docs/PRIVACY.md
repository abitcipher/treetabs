# treetabs privacy policy

Last updated: 27 October 2026

treetabs is a browser extension that shows your browser windows and tabs
as a tree. This policy explains what data it handles and where that data
goes.

## What treetabs reads

* **Your tabs and windows:** the address (URL), title and site icon of
  each tab, and which window it is in. treetabs needs these to draw the
  tree and keep it up to date.
* **The "treetabs" bookmark folder:** treetabs mirrors the tree into this
  folder, and reads changes you make there. It does not touch your other
  bookmarks.
* **What you add yourself:** custom titles, notes and groups.

## Where it is kept

Everything stays on your computer:

* **Without the companion app**, the tree is kept in the browser's own
  storage for this extension, along with daily backup copies and the tree
  window's settings.
* **With the optional companion app**, the tree is kept in a folder on
  your computer that you choose. The extension talks to the app through
  the browser's native messaging, which works only on the same computer.

The bookmark folder is part of your browser's bookmarks. If you turned
on bookmark sync in your browser, the browser syncs that folder like any
other bookmarks, under its own privacy policy.

## What treetabs does not do

* It sends **no** data over the internet: no analytics, no tracking, no
  advertising and no remote servers.
* It does not sell, share or transfer any data to anyone.
* It does not read the content of web pages, only the tab information
  listed above.

## Your control

* **Data → Export…** in the tree window saves the whole tree as a file.
* Removing the extension deletes the data kept in the browser.
* The companion app's folder stays until you delete it.
